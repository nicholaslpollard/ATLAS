## Strategy/research process issues surfaced

1. **Profit robustness versus retrospective search.** Large scenario grids have repeatedly yielded momentarily attractive settings; the cross-regime/capital-aware tests largely eliminate them. Require locked policy + prior-only folds, realistic quote friction, at least monthly/annual sign/drawdown/trade count checks, and explicitly retain flat-stay-cash comparator. Do not use 2026 May 12–Aug 11 protected outcomes to rescue weak development results.
2. **Source outcome censorship.** Never classify missing original stock minutes, missing exact options quotes, ambiguous provider dispatch, unknown exercise/cash or insufficient exit bid size as an actual rejected entry or a $0 P&L. The original quote availability denominator and exit stop conditions are as important as observed winning trades.
3. **Publication and simulation clocks.** One-second historical snapshot is not its true first-publication time and not a fill. A completed one-minute candle strategy is not a first-intraminute-tick breakout strategy. Verify decision, order and action clocks separately and stress price discrepancies, liquidity and spreads before promotion.
4. **Research ZIP history duplication/storage.** Multiple early aborted V99 and later corrected V99/V101 outputs coexist, with embedded ZIPs duplicating the loose signed source journals. Keep original signed archives immutable, maintain authoritative status manifest; do not count multiple copies of the same trial as independent samples.
5. **Core data path regression exposed by V104.** The first Windows V104 test gate had **41 pass, 6 fail**; all six failures are V38 archived new source path writes under long `pytest --basetemp` paths or downstream missing-source count. V104 stopped **before** any provider call; do not run acquisition from failing pinned revision `ad44ca26`. The successor V104 branch patches only NEW archive paths to `archive/<queryid[0:2]>/<full query SHA>.json.gz`, preserving full independently recorded original source SHA, compressed bytes SHA, exact query identity, and backward reads of previously indexed longer `<qid>_<sourceSha>.json.gz` files. New regression confirms filename, original source SHA and cache reuse. **Requires fresh Windows tests before provider acquisition.**
