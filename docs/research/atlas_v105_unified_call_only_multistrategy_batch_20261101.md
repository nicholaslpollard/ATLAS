## Target design: one genuinely causal, broad, source-first simulator (V106+)

1. **Lock strategy hypothesis registry before testing outcomes.** Include existing SPY 30–45 DTE / 0DTE stock-only decision family, V83–V88, V89/V97B 49/6, V55 separate completed-minute strategy, distinct first-tick ORB only if actual original stock trade/tick breakout is reconstructed; selectively include recurrent-stock fallback and options-only OI/Greeks strategies when original as-of source can be verified. Every change to entry thresholds generates a *new registry version*. No fitting strategy selection to available options contracts or historical successful exit quotes.
2. **Build point-in-time, per-event feature bus** from verified **already available at decision instant** original SIP minute bars, prior full day regular-session context, overnight/premarket evidence, dividends/corporate actions, options OI/Greeks when source interval is valid and has as-of delivery proof, and historical news metadata. **News age, revision clocks and verified source coverage** stay separate from sentiment availability. For no original news text as-of evidence, do NOT invent a sentiment feature or treat unknown as quiet.
3. **Generate all signal candidates first; register exact option queries later.** All strategies and parameter grids run on original stock/news prior-only features, logging each NO_SIGNAL, source-not-verified, candidate, rejected or blocked event. New strike/right/DTE/time variation creates its own exact source query identity. V38/V39 should retrieve/archive sources by SHA without unbounded redundant retries, tolerate individual uncertain provider outcomes and resume independent demands. Read data on demand rather than archive a 10-year full option universe.
4. **Replay genuine one-clock global capital** across overlapping strategies: first original action timestamp; one-slot $25k cash book; premium<= $500, qty<=4; exact original entry ASK and exit BID after bounded 1s/3s latency; bid/ask size, spread and minimum freshness; no hindsight substitution of invalid quote; 0DTE exercise/assignment cash and expiration handled explicitly or censor; conservative transaction fees and 2%+ modeled market-impact sensitivity. Prior-only policy for ties/arbitration, news switch and confidence cutoff.
5. **Batch many preregistered scenarios, not many hand-selected winners.** Structured limited threshold sweeps per strategy; exit stop/target grids and action delay; held-out adjacent future cohorts; joint family combinations, opportunity priority policy, daily loss cap, max concurrent trade count, stay-flat comparator; journal every considered and rejected event, cash effect, source SHA, news PIT evidence, broker non-fill caveats and earliest censor; calculate weekly/monthly/annual P&L and counts, risk/drawdowns, number of independent decisions, and sensitivity to worst trades.
6. **Select with train-only rolling folds.** More than one historical period for training; avoid reusing the 2026 May12–Aug11 previously-consumed master holdout as if untouched. Once policies frozen, run forward paper with real broker action/fill timestamps (prefer genuine new unseen sample). Retain all losers and original rejected decisions in signed immutable evidence; distinguish quote shadow from actual executed fills.
7. **Keep windows/data coverage honest.** This V105 combined study uses July 2025–April 2026 because exact shared-source families and original news decisions are available there. Source *availability* should never dictate rules or silently exclude sessions. A future broader signal pass should expose genuine option source gaps and retrieve new exact data through provider safely.
