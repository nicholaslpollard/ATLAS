## V51 code added

1. `packages/strategies/options_external_research_catalog_v51.py`: uniquely versioned 7 primary + 3 watch candidate specifications, claim type and period, original/reference URL, instruments, entry clocks, required observations, and explicit blockers. Every candidate has `atlas_historical_net_pnl=null`, no validated fills, no authority to promote or trade. Original SPXW and proposed SPY adaptations are different identities.
2. `packages/strategies/spy_0dte_opening_range_candidate_v51.py`: offline, source-only 09:30–09:35 **SPY 1-minute OHLC** high/low detector with published MWF version and separately registered all-weekday alternative. Every minute requires a source query ID, SHA reference and independent known-time/publication assertion. Uses **completed 09:30..09:34 candles**, not the still-open 09:35 minute; locates the first bar **after** 09:35 that could contain an upper/lower breakout. If BOTH boundaries fall within one minute, rejects as inherently ambiguous. Stores first possible minute, opening high/low, source provenance, all failure/weekday reasons. Its result **does not select the historical option strike or claim a trade**.
3. `exact_entry_demands()`: after a **separate independently verified first breakout tick, exact timestamp and underlying spot** arrive from a qualified original source, fixes original CALL or PUT and 0DTE ATM strike using nearest-dollar rounding, produces exact V39-shaped source requests for the selected contract at the first-known order reference clock and independently observed **+1s / +3s** hypothetical action clocks. **Actual fills, quote availability, provider 0DTE entitlement, stop/target sequence remain unproven.** Every new stop/exit timestamp would generate new source requests when the simulation advances; V51 does not pre-download a dense option tape or use future P&L to choose a contract.

**Important:** the original published ORB script may have used one-minute high/low observations without tick-accurate entry. V51's conservative no-lookahead first-tick requirement is a documented **reproducibility-evidence guard**, not a claim that the developer's trade list can already be exactly regenerated. Until that evidence is available, produce a preview-only first-breakout candidate population, not strategy returns. Even when a minute bar has source provenance, its `first_publication_proven` flag must eventually be independently certified by an ATLAS source admission adapter; caller-supplied flags alone cannot prove original publication.

### Single-leg breakout account replay added in the same V51 batch

`packages/simulation/spy_0dte_orb_single_long_reference_v51.py` adds a **source-supplied single-CALL or single-PUT** 0DTE quote-reference replay; this was deliberately not squeezed through V50's two-long-leg straddle kernel. It consumes only SHA-pinned ORB candidate/tick/contract-identity receipts and independent historically known bid/ask at order and action clocks. Every selected opportunity produces a source-linked decision event, including outside weekday, no breakout, missing tick, missing or crossed/wide quotes, excessive adverse price drift, insufficient $500 premium budget, or unresolved existing position. The first valid contract is fixed using the separately known original breakout tick, not after seeing its future P&L.

The published **$500 premium** cap is applied to whole contracts **before commissions**, exactly matching the author's size illustration; modeled account cash separately includes $0.65 per option contract per side. The published **+100% or −50% triggers compare the observed option exit bid against the actual original entry ask**, not net-after-fee account P&L (which is calculated separately). The time exit is 15:30. A missing/unqualified intraday observation or gap above 60 seconds is **censored** and blocks false implied first-stop/profit fill; even a gap-free sequence is a **quote-observation reference**, not evidence of true intrabar stop ordering or broker execution. Final account equity is `null` for any unclosed/unpriced open option, not silently reduced to settled cash. Support one action-latency clock at a time (1s original conservative reference vs independent 3s experimental) and adverse drift caps 0.5%, 1%, 2%; all variants are separately labeled.

This engine has no provider/broker calls and **cannot use V46 scenario-derived non-PIT volatility screens as signals**. The tests only exercise fictional unit-test market observations; actual recorded 0DTE stock-tick, exact-call/put option quote availability, complete intraday stop/target path and financial account P&L are pending workstation/ThetaData source qualification. The original source's optimization-chosen MWF and five-minute opening window remain development hypotheses, not new held-out winners.

**Track B (reproduced short-premium reference): WealthyOption.** Map original open-source Java strategy/quote/margin assumptions into explicit data schema; start with *SPY adaptation* if 0DTE/SPXW entitlement and margin data are limiting, but never label it the original SPXW. Add independent sleeve capital, collateral, stateful GTC exits and expiration settlement. Test high-tail losses and no-buying-power cases before reporting net alpha. Require published source vs independently reproduced differences retained, especially 10-second vs 5-minute exit decisions and fill modeling.

**Track C (multi-leg platform foundation): Sandvand / MEIC / Ruchel.** Generalize positions to N signed legs, exact original underlying and expiry, optional mixed strikes, per-leg/side stop and state, atomic vs staged/partial executions, collateral and account shared capital, cash vs physical expiration, SPXW vs SPY contract assignment. All relevant positions must be supported simultaneously for MEIC; only running four legs through V50's one-position paired-straddle slot would produce false feasibility. First validate four-leg payoff identities and no-capital overcommitment using no-provider fixtures; then test actual historical SPXW intraday data when verified accessible.

**Historical truth and profitability gate:** collect all opportunities and reasons whether traded or not; exact source first-known time, no hindsight strike selection, independent action price, fees/spread, assignment, unrealized mark, tail-loss stress, weekly/monthly/yearly account P&L and full-term capital usage. Fresh untouched future evidence or prospectively logged paper validation is required for finalist claims.
