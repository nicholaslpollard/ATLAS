## What changes — and what does not

\`scripts/run_marketdata_2022_bulk_acquisition_v1.py\` is the ONE operator handoff for the frozen remaining **2022 additive shards 26–70**. The accepted original 2022 three/month cohort and additive 0–25 are never requested again. An exact contract history request is identified by the same original OCC symbol, \`2022-01-01\` through inclusive expiration (exclusive next day), regardless of an expanded membership plan.

* Preflight verifies the accepted frozen 0–25 quote plan and original 2022 three/month source **once**, loads the accepted native-development replay **once**, and SHA-verifies the needed canonical native raw OPEN units for all remaining unbound source shards **in one batched operation**, not repeatedly for each of 45 shards. Each shard then receives only its exact selected opportunity IDs/opens from that verified batch and freezes its own original source/plan SHA and binding before any provider GET. The global original 2,812-key fingerprint and unique physical keys are checked. On a fully bound resume, the expensive replay/native-unit scans are bypassed and original SHA-bound files are read. No protected outcome/master return data are read.
* Source acquisition uses independent original per-shard plan locks, durable attempt-before-GET, actual original body/receipt SHA and exact zero-credit 404 proofs. Up to **four initially / eight ceiling** disjoint shards run concurrently. Each shard issues no more than ten new GETs in a wave, leaving a strict inter-wave original receipt/credit barrier. Network-worker target grows by two if measured throughput permits, and falls back if a higher worker setting materially worsens it. The global credits budget reserves conservatively for every planned in-flight source wave; it is a stopping target, not a hard guaranteed cost ceiling.
* After ALL 45 new shards are exact complete/gap terminal with no pending, freeze the original prior-session **single accepted 28–60-DTE monthly-expiration CALL ±8% raw-as-traded OPEN** plan through shard 70. No quote GET is permitted after a partial/uncertain chain stage. All original 2,725 quote receipts must be intact and are reused through the V1 exact physical cache.
* Quote history acquisition uses 16 initial, up to 24 concurrent network I/O workers with observed GETs/sec and adaptive per-batch sizing. Entire original batches finish before new dispatch; uncertain 429/timeout/quarantine cannot produce a blind retry or a new batch. Each exact full EOD series is one provider GET, not one GET per trading day. The operator's budget is shared by both chain and quote stages.
* If all quotes reach exact terminal receipt states, run ONE offline audit of all stored 2022 additive histories (original plan + receipt/body SHA, observed EOD rows, reported positive/zero volume and date extrema). No provider GET is made by that final audit. It does not establish historical executable fills, portfolio returns, or a passed liquidity test.

CLI default ceilings: **1,800** new chain attempts, **6,000** new quote attempts, **6,300 observed credits total**, D: current research-category/quota floors, min observed provider remaining 400 plus in-flight reservation. With the last observed remaining 6,909 and no competing activity, this protects headroom; actual provider headers at runtime are authoritative. If credits are exhausted before completion, the process stops with a truthful partial status and nonzero exit, after saving original evidence. Re-run the exact same command after reset if the user elects to continue; never reissue a paid original because an earlier run stopped. A single process does not silently wait across days or initiate a second account session. One global workstation lock prevents overlapping copies; an existing lock is **never removed by a non-owner**.

The acquisition is limited to the frozen accepted 2022 **additive monthly CALL** universe. The original separate 2022 three/month provider chains are not automatically part of this V2 quote plan, and no extra expiration, PUT, 2021/2023/2024/2025 cohort, historical intraday bid/ask, or PAPER/LIVE promotion is implied. Expansion to other years needs its own accepted native-development opportunity/point-in-time source adapter and provider entitlement. The 2022 full monthly CALL EOD corpus is an acquisition milestone, not a complete options-simulation data specification.
