## Methodology and interpretation constraints

1. This is a true H2 **newly acquired historical source cohort** relative to previously inspected 2025 H1 receipts; nevertheless, **all H2 outcomes are now inspected** and no further revised parameter suite may be labeled an untouched H2 holdout. The V76 policy roster was selected after H1 results, and all five use the **same frozen SPY M/W/F original entry**, not different entry strategies or stocks fallback.
2. Widespread backtest optimism remains possible: option bid snapshots and displayed size are not proof of marketable sell-to-close execution; order limits, queue priority, partial fills, cancellations, rejected orders, broker expiration intervention, option margin/cash and assignment have not been independently validated. Physical-settlement SPY is not guaranteed an intrinsic cash payment.
3. The independent V78 auditor did **not** have the full per-day event archives from the operator workstation, only the signed daily per-scenario event summaries with per-gzip SHA references. Full actual option archive bytes and events are retained locally and must be verified before changing the live execution model.
4. The negative weekly and monthly results under almost all variants and the runner outlier dependence mean **none passes ATLAS's profitability-by-window requirement**. Do not promote any of these as viable strategy alpha.
5. Next durable simulator work: (a) reconcile quote-to-order venue, latency, drift, cancel/replace and partial-fill state machine in shadow/PAPER; (b) causal **distinct strategy-family** registry (e.g. theta-income defined-risk structures, directional options+stock filters, volatility regime variation, stock fallback), with dynamic requirements by selected candidate, cache-first original source acquisition; (c) shared capital/margin/exposure/risk budgeting and actual cash-ledger censor; (d) causal walk-forward search on earlier folds and genuinely untouched follow-up windows, with one-week, monthly, yearly, drawdown and friction gates.
