# V97 design — broad causal CALL-only historical strategy laboratory

**2026-11-01; design only, NOT an executable historical backtest or proof of profitability.**

## Motivation and scope

User explicitly requests a single orchestrated batch that can explore existing ATLAS strategies, individually tuned variants, position/exit adjustments, strategy-selection and combination rules, and as-of available news. Long **CALL** options are the primary requested initial instrument (no PUT purchases, shorts, spreads or stock executions in the CALL-only experiment). This is a deliberately new experiment alongside the *rejected* earlier six-family SPY CALL/PUT 0DTE portfolio. No earlier source journal is rewritten and no historical outcome is treated as training data for its own session.

Prior independently audited V95 found **0 of 163** complete 8-cohort configurations positive across all eight. The unchanged balanced/3s/10s/2%-BID combined portfolio lost a nominal **$6,915.76** across eight distinct, unequal historical periods. Eight previously favored V91 runner variants were the same tiny early-reversal population and no validated trade edge. Therefore broad sweeps are **discovery / hypothesis generation**, never independent alpha validation or permission to live trade. Causally later historical periods already inspected cannot be relabeled untouched simply by freezing the rules now.

## What exists in repository, versus what HAS been historically option-tested

1. **Do not confuse directory names with implemented strategies:** the current GitHub tree has **106** Python files under `packages/strategies/`, **78 are exactly zero-byte placeholders**, and **28 contain nonempty code**, including infrastructure, contracts, registries and successor logic (NOT 28 independent working strategies). The nonempty `reference_library.py` registers **9** direction-specific stock strategy specifications and `registry.py` defines **8** daily-feature rules, with overlapping concepts, long/short directions, and no automatic exact historical CALL adapter. Many named trend/breakout/gap/mean-reversion/reversal/support/resistance/volume/volatility/relative-strength/composite individual files are **empty**, not runnable strategies. The generic daily reference library/strategy registry, stock signal features and synthetic sweep fast lane are **not** equivalent to running those rules on original historical option contracts, exact entry/exit two-sided NBBO, margin and portfolio cash. Count only importable rule implementations that pass feature, causal-time and option-source gates.
2. V82/V83 three earlier original option entry families and V89 six new source-linked original SPY stock-signal hypotheses have some actual SHA-linked historical option quote-replay evidence. These **nine historical entry families are not the whole strategy registry**. Their original dual CALL/PUT hypothesis selection must NOT be relabeled as a profitable CALL-only portfolio. The CALL-only experiment can use already qualified CALL tape scopes; when a bullish CALL entry is newly generated by different rules and its exact historical option tape is absent, the simulation **abstains until a separate causal source-plan acquisition gate obtains exact source**.
3. V51 external candidates include a SPY 0DTE ORB long option idea, plus SPXW short multi-leg candidates and 1DTE ideas. Their published backtests, seller anecdotes or synthetic contract demonstrations are **not validated ATLAS live results**. SPXW or short premiums are explicitly outside the initial CALL-only scope.
4. `packages/data/offline_multiyear_news_context_v1.py` gives an original receipt-and-SHA-verified Alpaca historical **news metadata context from Jan 2021 through the accepted 2026 historical cutoff**, including a December 2020 lookback. It makes provider requests 0 and attributes effective availability at `max(created_at,updated_at)` of the retrieved revision; a later-revised article cannot be backdated. It supports article **counts**, not certified as-of sentiment or true full-text revision availability. Jan 2018–Dec 2020 are **NEWS_UNAVAILABLE** for the currently accepted PIT-news integration; use explicit no-news-control and source-unavailable cohorts rather than 0 headlines. Historical source news coverage does not include 2026 dates after accepted cutoff.
5. The original options source V38/V39 exact contract archive is query-ID keyed, SHA-verified and can be read once for many offline scenarios. V84/V86 include real 1s historical bid/ask quotes and actual quote reference clocks, but original action-limit marketability does NOT establish fills or bid size executable at account quantity. V95 2020 retains **three undecided exact sources**; do not force 2020 into any complete-year economics. Protected 2026-05-12..08-11 master holdout remains sealed.

## Batch architecture: one operator command, multiple SOURCE-GATED stages

### Phase 0 — evidence and capability inventory, no provider

- User runs `scripts/run_spy_v96_research_evidence_upload_packets.py`; upload packets cover existing original V83–V95 ZIPs, with per-file SHA and independently testable packet CRC. Do **not** zip the entire data/research root or raw D: provider caches.
- Build an *implementation-based* strategy capability register from actual importable rules, required features, decision clock, minimum warm-up, direction, instrument conversion and risk contract. Per candidate mark `EXACT_ORIGINAL_OPTIONS_READY`, `CAUSAL_STOCK_ONLY`, `PIT_NEWS_METADATA_ONLY`, `SYNTHETIC_ONLY`, `EXTERNAL_IDEA_NOT_EXECUTABLE`, or `MISSING_SOURCE`. No label of *all strategies tested* without running exact original CALL tapes for every candidate.
- Inventory exact original CALL option quote coverage, source query ID/status, available timestamps, bid/ask **and sizes**, per year, and current free storage before any GET. Never trust a source *calendar month* SHA alone to prove an *individual decision* could execute.

### Phase 1 — derive every strategy's CALL candidate stream from causal inputs

- For each session of permitted developmental periods, run all feasible strategy entry algorithms independently, using **only features whose publication/effective timestamps are <= decision time**, enough prior warm-up, and deterministic strategy version ID and parameter hash. Use `NO_SIGNAL`, `MISSING_PIT_FEATURE`, `NO_NORMAL_SPY_EXPIRY`, `PREDECISION_NEWS_UNAVAILABLE`, `STOCK_SOURCE_REJECTED`, `CALL_NOT_DIRECTIONALLY_QUALIFIED`, and `OPTION_TAPE_NOT_AVAILABLE` distinct no-trade states. All candidate choices and rejections are logged regardless of outcome.
- CALL-only direction: bullish setup -> **buy to open one CALL**, exit by **sell to close**; a bearish setup is NO_TRADE, **not** silently converted into a bullish CALL or assumed PUT. Multiple strategies can make same/simultaneous candidate; deduplicate exact provider source requests by `query_id` while retaining each strategy's decision provenance.
- Contract selection must specify as-of underlying mid/last, expiry actually listed **on that historical date**, contract strike/ATM or separately declared delta-target when decision-time Greeks are source-verified; DTE eligibility, OCC deliverable, lot multiplier, size, maximum permitted entry spread, premium size, liquidity and time cutoffs.
- A changed rule, strike or decision clock that produces a new exact historical contract/cutoff requires an **additional, separate source requirement**; do not force it onto a fixed old contract merely because it has convenient successful exit quotes.

### Phase 2 — news/market context, and source acquisition once per distinct query

- At each decision, obtain original contemporaneously available SPY 1-minute bars, prior-session volatility/trend/regime indicators, previous *completed* session outcomes and original local stock source SHA.
- For dates Jan 2021 through original available historical-news cutoff, optionally join verified original PIT **headline-count metadata** in preceding 24h and 7 days with effective `max(created_at, updated_at)`. Distinguish `NEWS_NONE_VERIFIED` from `NEWS_NOT_COVERED`; unknown remains null, never zero. A **positive / negative news sentiment** rule is **BLOCKED** until historical article text/revision and classifier were demonstrably available as-of signal and their inputs/version fully pinned. No use of hindsight classifications on 2018–2020 or in sealed 2026 holdout.
- Build **one** union of original exact CALL tape requirements for all declared candidate variants. Cache-first source acquisition only when a qualifying historical decision actually needs an exact source. Preserve SHA-linked append-only request/dispatch logs, ambiguous dispatch states, archive CRC/source SHA, query count, cost, bytes and current storage free. Provider GETs serialized against the current V38 SQLite cache; pause on a specific ambiguous query **without retry**, continue other independent scopes safely. No live broker/paper orders in historical runs.
- Do not fetch the entire 10-year SPY chain universe or re-fetch the same 1s options tape per exit-policy tuning. Stored complete tape is reused offline for ALL downstream scenario variations.

### Phase 3 — many offline scenarios on the same source tape, with trial IDs

Use a **bounded preregistered grid**, not a combinatorial unlogged search over millions of labels. The following are conceptual parameter axes; every one requires a precise module/feature contract and source readiness before becoming executable:

| Axis | Discovery examples (all versions recorded) | Source requirement |
| --- | --- | --- |
| Strategy identity | Existing qualified bullish opening-range, trend, momentum, pullback, mean reversion, gap, volatility and reversal entry rules | Rule's exact closed-bar and prior-history as-of features; exact CALL contract tape |
| Signal strength | 3 ex-ante magnitude thresholds per strategy only where a meaningful registered scalar is available | Each different entry date/strike/clock requalifies source |
| Entry clock | 09:35, 09:40, or 09:50 only for explicitly registered closed-bar rules; separate 1s/3s/5s/10s action-delay sensitivities | Matching earlier strategy decision and later exact 1s original quote |
| Trend/regime gate | No filter; deterministic as-of positive trend; as-of realized-volatility regime | Prior-only original stock history; avoid future full-day SPY range or same-day closing mark |
| News gate | OFF; verified 24h article count >=1; verified article-count 7d rank based on prior history | V2 verified PIT metadata; unavailable news is NA, not zero |
| Execution/stop | Frozen prior original control/balanced/runner policy plus separately preregistered conservative wide/tight bounds; 1s/3s/5s/10s lag; 0/3/10/30s limit rest | Historical original bid/ask **and size**, cancel/replace conservatism, explicit unfilled orders |
| Cost/microstructure stress | 2%, 4%, 6% adverse exit BID haircut diagnostic; original entry spread guard; stricter quote freshness and quote size | Pure posthoc sensitivity DOES NOT fabricate a new fill, execution sequence or favorable selection |
| Position sizing | Fixed $100/$250/$500 maximum premium, 1–4 contracts with $25k single-account cash, bounded max entries per day and max day loss | Realistic cash reservation, signed all-action chronological ledger |

Apply risk/latency thresholds at each decision using information available at that instant; **trades may be skipped due to earlier hypothetical losses only if those earlier outcomes and account positions were already known at that decision time**. No comparing an already-discovered trial's result with a later signal when deciding an earlier trade. A scenario producing missing mandatory tape is `INCOMPLETE_SOURCE`, not zero PnL or a secretly reduced sample.

### Phase 4 — combine live-like strategies with one account

- Independently measure each qualified CALL strategy, then test registered blends: all-qualified; momentum/trend only; reversal/pullback only; volatility-conditioned family priority; and **prior-fold-only** dynamic allocation with conservative minimum opportunity and performance calibration. **Do not select today's strategy using its own later exit or today's completed high/low.**
- At simultaneous strategy decisions, choose deterministically using only as-of score, risk, source availability and stable tie-breaker; one slot and $25k starting cash by default. No adding separate solo strategy P&Ls to claim one shared cash account. Cap daily premium, loss, correlation, reopen/cooldown and session end. Record all eligible rejected alternative CALLs, opportunity cost, quote limit evidence, cancellations and reserve release.
- Run the whole decision sequence with the **same planned real-time event ordering** as the future live engine: timestamped quote and signal publication, order construction, risk preflight, simulated acknowledgement/rejection, child order states, partial fill/expiry resolution, next update, exit/risk change, day/month year accounting.

### Phase 5 — score and review every experiment without selection leakage

- Stage all trial IDs, code/source SHA, parameter grid, period membership and candidate/source counts **BEFORE** calculating outcome PnL. Persist immutable trial table with winners **and losers**, no-entry/rejection reason, missing features/tape, modeled latency quote marketability/size, P&L, cost, max drawdown, losing streak, return distribution, median and largest two winners, PF, hit rate, dollars at risk, positive weekly/monthly/yearly windows and confidence intervals.
- Use chronological **walk-forward selection** where each model/weight/regime threshold trains **only on earlier periods** and evaluates on later periods, and does not peek at later outcomes to pick parameters. The previously opened 2018–2026 cohorts are exploratory/not independent holdouts. The sealed **2026-05-12..08-11** master period must **not** be used to rescue strategy choices. Future fully prospective PAPER is necessary before asserting executable profit.
- Report: all 1st-level original models, all tuned variants, every registered combined model, tail/execution stresses, per-regime results, sample sizes, coverage shortfall and multiple-testing effects. No ranking a winner with only a few lucky trades. Treat a wide parameter plateau and repeatability in multiple time-separated regimes as **research evidence**, not proof.
- Only after offline evidence audit can a CALL-only final engine candidate be considered for prospective paper simulation. Actual live trading authorization is a completely separate gate, **not** granted by this plan.

## Implementation stages, not performance claims

**V96 (implemented):** SHA/CRC verified user upload packet tool for all relevant signed research source ZIPs, with no provider calls or raw data upload; regression-tested locally once user runs it.

**V97A (next code):** Instrument/strategy/feature capability census + PIT stock/news source coverage + original CALL tape request-plan preview, **zero provider calls**, report all blocked/available strategies. This is necessary to determine which entry threshold/clock adjustments actually can be tested historically.

**V97B:** One union CALL-only source planner + historical as-of feature joins; 2018–2020 news unsupported; signed source request/cache indexes; no incomplete source PnL. Source acquisition separated from offline scenarios.

**V97C:** Large batched offline scenario runner reusing original call tape, factorized scenario grids with trial quotas; multi-scenario one-account blends; signed all-event immutable journals. Do **not** claim the synthetic `strategy_sweep_fastlane_v1` is this historical runner without rewriting its source authority and matching chronology.

**V97D:** Independent evidence audit and causal replay consistency, 2020 uncertainty preserved, sealed master holdout skipped; walk-forward summaries. If the new broad campaign shows uniformly negative CALL economics, stop or pivot mechanism rather than tuning the same historical sessions indefinitely.

**User preference honored:** Maximize **meaningful experiments per source request**, call options first, historical news used *only where point-in-time qualified*, no fitting to convenient data, maximal useful signed decision and nontrade logs; make progress toward a realistic live-equivalent engine, not a backtest that merely looks profitable.
